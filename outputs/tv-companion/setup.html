Connecting…

1. Connect your TV

  1. On the TV: Settings → About → select the Android build number seven times.
  2. Open Developer options and enable network debugging or Wireless debugging.
  3. Enter the TV address below, connect, and accept the authorization prompt on the TV.
  4. Select Install / update DuoBuddy on this TV, then add your API key in step 2.

Android TV or Google TV · Android 8 or later. Keep this Mac and the TV on the same home network. Allow local-network access if macOS asks.

For network debugging, enter the TV’s IP address (port 5555 is added). For Wireless debugging, use its IP address and connection port, which differs from the pairing port.

Pair with a wireless debugging code

On the TV, choose “Pair device with pairing code”. Enter the address, port and six-digit code shown there, then select Connect TV below. Leave these blank for an already paired TV.

Leave blank to find a microphone remote automatically. When you enter a name, DuoBuddy uses only inputs with that exact name.
